Zwei Meta-Pixel in einem Shop sind keine Redundanz. Es sind zwei Versionen der Wahrheit.

Kamran Arshad13. Aug. 20268 Min. Lesezeit

Zwei Meta-Pixel in einem Shopify-Shop geben Ihnen kein Backup. Sie geben Ihnen zwei unabhängige Aufzeichnungen derselben Events, und nichts hält sie ehrlich. Ist eines falsch konfiguriert, bekommen Sie zwei widersprüchliche Verkaufszahlen ohne Warnung, und Meta gibt bereitwillig Budget aus, um auf die falsche zu optimieren.

Suchen Sie nach „mehrere Facebook-Pixel Shopify“ und sehen Sie sich an, was zurückkommt. App-Einträge, die die Installation mehrerer Pixel verkaufen. Anbieterleitfäden, die erklären, wie man ein zweites, drittes, viertes Pixel hinzufügt. Tutorials, die es als fortgeschrittene Taktik darstellen.

Fast nichts darüber, was passiert, wenn diese Pixel sich widersprechen. Das ist der Artikel, den ich mir gewünscht hätte, bevor ich ein Konto geprüft habe, in dem die Antwort 30 bis 40 % des Tagesbudgets kostete.

Wie man bei zwei Pixeln landet

Selten absichtlich. Die üblichen Wege:

  • Eine Agentur hat eines installiert und ist gegangen, und die nächste Agentur hat ihr eigenes installiert, ohne nachzusehen.
  • Eine Marketing-App eines Drittanbieters hat bei der Einrichtung ihr eigenes Pixel hinzugefügt, oft ohne es deutlich zu machen.
  • Jemand hat vor Jahren ein Pixel in theme.liquid eingefügt, und der offizielle Vertriebskanal wurde später verbunden.
  • Jemand hat gelesen, dass mehrere Pixel Redundanz bringen. Das tun sie nicht.

Der rote Faden: Keiner der Beteiligten wusste, dass das andere Pixel existiert. Genau das macht es schwer zu erkennen: Jeder nimmt an, dass das Pixel, das er installiert hat, das Pixel ist.

Was tatsächlich schiefgeht

01

Sie können unterschiedliche Summen melden, und beide wirken plausibel

Zwei Pixel, die unter verschiedenen Bedingungen ausgelöst werden, erzeugen zwei verschiedene Kaufzahlen. Keine wirkt offensichtlich falsch, weil keine null ist. Am Ende wählen Sie die Zahl, der Sie glauben, danach aus, welches Dashboard Sie gerade geöffnet haben.

02

Kampagnen optimieren auf das Pixel, an dem sie hängen

Das ist der teure Teil. Kampagnen sind auf ein bestimmtes Pixel konfiguriert. Meldet dieses Pixel ungenau, optimieren diese Kampagnen auf ein Signal, das nicht der Realität entspricht, und das Auslieferungssystem von Meta findet immer mehr Menschen, die dieses ungenaue Signal auslösen.

03

Ein falsch konfiguriertes Pixel kann Käufe melden, die nie stattgefunden haben

In dem Konto, das zu diesem Artikel geführt hat, meldete das zweite Pixel, installiert von einer Drittanbieter-App, Käufe ohne zugehörige Shopify-Bestellungen. Die daran hängenden Kampagnen zeigten einen starken ROAS. Im Ads Manager sahen sie wie die Gewinner aus. Im Shop hatten sie nichts Nachverfolgbares gebracht.

Meta meldete rund 100 Bestellungen. Shopify zeigte 55 bis 70. Rund 30.000 bis 40.000 PKR eines Tagesbudgets von 100.000 PKR flossen in Kampagnen, die auf das Pixel optimierten, das Verkäufe erfand.

04

Ihre Zielgruppen und Optimierungsdaten werden aufgeteilt

Selbst wenn beide Pixel korrekt sind, lernt jedes nur aus dem Traffic, den es sieht. Retargeting-Zielgruppen werden pro Pixel aufgebaut. Maschinelles Lernen läuft pro Pixel. Wer seine Daten auf zwei Pixel verteilt, gibt beiden weniger davon, das Gegenteil von Redundanz.

Woher diese Zahlen stammen

Ein Shopify-Konto, das ich übernommen und geprüft habe, eine Hautpflegemarke mit Meta-Anzeigen bei rund 100.000 PKR pro Tag. Der Kunde hat mich gebeten, ihn nicht zu nennen, also tue ich es nicht. Die folgenden Zahlen sind so, wie sie während dieses Auftrags im Konto standen.

Das ist ein Konto, keine Studie. Ich gebe Ihnen den Mechanismus und ein durchgerechnetes Beispiel, keine Statistik über die Branche. Und ich nenne hier keine genauen Auftragsdaten, weil ich sie lieber weglasse, als sie zu schätzen.

Jedes Pixel in Ihrem Shop finden

Prüfen Sie alle drei Stellen. Ein Pixel kann an jeder davon unabhängig installiert sein, und nichts gleicht sie miteinander ab:

  1. Einstellungen → KundenereignisseHier liegen benutzerdefinierte Pixel, auch solche, die Apps hinzugefügt haben. Lesen Sie jedes und notieren Sie seine Pixel-ID.
  2. Der Facebook & Instagram VertriebskanalDie offizielle Integration. Notieren Sie die verbundene Pixel-ID.
  3. Onlineshop → Themes → Code bearbeitenDurchsuchen Sie theme.liquid nach fbq und connect.facebook.net. Von Hand eingefügte Pixel verstecken sich hier jahrelang.
  4. Im Browser bestätigenLaden Sie Ihren Shop, öffnen Sie die DevTools, filtern Sie den Network-Tab nach facebook und lesen Sie die Pixel-IDs der ausgehenden Requests. Nur dieser Check zeigt, was tatsächlich läuft, und nicht, was konfiguriert ist.

Wenn Sie mehr als eine Pixel-ID finden, haben Sie die Situation, um die es in diesem Artikel geht.

Eines sicher entfernen

Nicht einfach löschen

Bevor Sie ein Pixel deaktivieren, finden Sie heraus, welche Kampagnen darauf optimieren. Als ich in diesem Konto das Drittanbieter-Pixel deaktiviert habe, stoppte jede daran hängende Kampagne. Das war das richtige Ergebnis, denn diese Kampagnen liefen auf einem Conversion-Signal, das nicht echt war, aber so etwas sollte man in einem Kundenkonto nicht überraschend entdecken.

  1. Kampagnen den Pixeln zuordnenNotieren Sie für jede aktive Kampagne, gegen welches Pixel ihr Conversion-Event konfiguriert ist.
  2. Jede Gruppe mit Ihrem Shop abgleichenNehmen Sie eine abgeschlossene Woche. Können Sie die Bestellungen nachverfolgen, die jede Gruppe beansprucht? Bei einer Gruppe geht das meist überhaupt nicht.
  3. Das Pixel behalten, das Sie verifizieren könnenMeist die Integration über den offiziellen Vertriebskanal, weil Sie bestätigen können, was sie installiert und wie.
  4. Den Kunden warnen, dass der gemeldete ROAS sinken wirdDas wird er. Am Geschäft hat sich nichts geändert, Sie zählen nur keine Dinge mehr, die nicht passiert sind.
  5. Zwei Tage warten, dann neu aufbauenLassen Sie saubere Daten zusammenkommen, bevor Sie die Kampagnen auf dem verbleibenden Pixel neu aufbauen. In diesem Konto war das Bild nach ein bis zwei Tagen klar.

Die Ausnahme, die Sie kennen sollten

Es gibt einen legitimen Fall für mehrere Pixel: eine echte Vereinbarung mit einer Agentur oder einem Partner, bei der eine zweite Partei für eine bestimmte Kampagne eigene Conversion-Daten braucht, und beide Pixel bekannt, dokumentiert und gewollt sind.

Das haben die meisten Shops nicht. Die meisten Shops haben ein Pixel, das jemand vergessen hat, und das ist etwas völlig anderes. Der Unterschied ist, ob Ihnen jemand jetzt sofort sagen kann, wofür jedes Pixel da ist.

Wenn Sie das nicht für jedes Pixel in Ihrem Shop beantworten können, haben Sie keine Redundanz. Sie haben eine ungeprüfte zweite Meinung, auf die Ihr Budget still hört.
